## Table of Contents

## Technology

- Framework/Library : Javascript, Node and Express
- Database : Postgress

## Installation

Project uses Node(23.9.0) and npm (10.9.2)

1. Change directory to `courier-collection-stage-2`
2. Copy `.env.example` to `.env` and adjust values if needed
3. Run `docker compose up -d` to install dependencies and start the application

## Ports

Stage 2 uses port **5001** (API) and **5433** (PostgreSQL) so it can run alongside stage 1.
